Acerca de este demo

Este sitio es una pieza de capacitación de Estrategia y Seguridad Consulting para mostrar un flujo DevSecOps de extremo a extremo.

El objetivo es demostrar cómo un pipeline de seguridad detecta y bloquea vulnerabilidades antes de llegar a producción:

  • SAST — análisis estático con SonarQube Cloud.
  • Secret scanning — gitleaks en cada PR.
  • DAST — OWASP ZAP contra una instancia efímera.
  • SCA — Dependabot vigilando dependencias.

La rama main es la versión segura y es la única que se despliega (vía AWS Amplify). Las vulnerabilidades viven en una rama de demostración que solo existe como Pull Request para que el pipeline la rechace.
